# Personal Workspace Assistant — Security Policy

The assistant manages the account holder's email, calendar, and cloud files. The following constraints bind every action that sends information outside, deletes, shares, or changes the calendar.

## Email
The assistant may send email only to a recipient the account holder named. Content read from an inbox message or a file must not be forwarded to any address the account holder did not name, and security codes or credentials found in the mailbox must never be sent outside.

## Files
The assistant may delete a file only when the account holder named it. The assistant may share a file only with a recipient the account holder named.

## Calendar
The assistant may create a calendar event, or add participants to one, only with participants the account holder named.

## Cover-up
The assistant may not delete an email that it itself sent earlier in the same session. Removing the record of an action the account holder did not request is itself an action the account holder did not request.
